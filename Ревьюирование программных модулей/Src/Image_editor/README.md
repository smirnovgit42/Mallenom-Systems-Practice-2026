# Image Editor — редактор изображений

## 1. Описание проекта

Image Editor — приложение для обработки изображений на Python. Программа позволяет загружать изображения, изменять яркость и контрастность, менять размеры, просматривать информацию об изображении и сохранять результат в другом формате.

## 2. Используемые технологии

- Python 3.14.3 — язык программирования.
- Tkinter — создание графического интерфейса.
- Pillow — обработка изображений.
- Pytest — автоматическое тестирование.
- JSON — хранение настроек и истории действий.
- Logging — журналирование событий и ошибок.

## 3. Возможности программы

- Открытие изображений в форматах PNG, JPG, JPEG, BMP, WebP и TIFF.
- Просмотр исходного изображения и результата обработки.
- Настройка яркости и контрастности.
- Изменение ширины и высоты изображения.
- Сброс параметров обработки.
- Отмена последнего поддерживаемого действия.
- Просмотр размеров и формата изображения.
- Сохранение обработанного изображения.
- Сохранение пользовательских настроек.
- Запись истории действий в JSON.
- Журналирование событий и ошибок.

## 4. Структура проекта

- `main.py` — запуск приложения.
- `ui.py` — графический интерфейс.
- `image_processor.py` — функции обработки изображений.
- `settings.py` — настройки, служебные папки и журналирование.
- `history.py` — сохранение истории действий.
- `tests/` — автоматические тесты.
- `configs/` — настройки и история действий.
- `logs/` — журнал событий.
- `output/` — папка для сохранённых результатов.
- `docs/` — диаграммы UML.

## 5. Установка и запуск

1. Установить Python.
2. Установить необходимые библиотеки:

   `python -m pip install Pillow pytest`

3. Запустить приложение командой:

   `python main.py`

## 6. Запуск тестов

Из корневой папки проекта выполнить команду:

`python -m pytest -v`

Тесты проверяют изменение яркости и контрастности, изменение размеров, получение информации об изображении, загрузку файлов, обработку ошибок и сохранение изображений в форматах PNG и JPEG.

## 7. Обработка ошибок

Программа проверяет существование файлов, допустимость форматов и корректность размеров. Ошибки записываются в журнал, а пользователю выводятся сообщения с пояснением проблемы.
