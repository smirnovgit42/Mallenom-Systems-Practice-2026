# Image Editor — редактор изображений

## 1. Описание проекта

Image Editor — настольное приложение на Python для обработки изображений. Программа позволяет загружать изображения, изменять яркость, контрастность и размеры, просматривать результат и сохранять его в выбранном формате.

## 2. Используемые технологии

- Python 3.14.3 — язык программирования.
- Tkinter — создание графического интерфейса.
- Pillow — обработка изображений.
- JSON — хранение настроек и истории действий.
- Logging — журналирование событий и ошибок.

## 3. Возможности программы

- Загрузка изображений форматов PNG, JPG, JPEG, BMP, WebP и TIFF.
- Предварительный просмотр исходного изображения и результата.
- Изменение яркости и контрастности.
- Изменение ширины и высоты изображения.
- Сброс параметров обработки.
- Отмена последнего поддерживаемого действия.
- Отображение характеристик изображения.
- Сохранение результата в выбранном формате.
- Сохранение пользовательских настроек.
- Ведение истории действий.
- Запись событий и ошибок в журнал.

## 4. Структура проекта

- `main.py` — запуск приложения.
- `ui.py` — графический интерфейс.
- `image_processor.py` — обработка изображений.
- `settings.py` — настройки и журналирование.
- `history.py` — история действий.
- `configs/` — настройки и история действий.
- `logs/` — журналы событий.
- `output/` — сохранённые изображения.

## 5. Установка и запуск

Для работы приложения необходим Python и библиотека Pillow.

Установка библиотеки:

`python -m pip install Pillow`

Запуск приложения из корневой папки проекта:

`python main.py`

## 6. Обработка ошибок

Программа проверяет существование файлов, допустимость форматов и корректность размеров изображения. При возникновении ошибок пользователь получает соответствующее сообщение, а сведения об ошибках записываются в журнал.
